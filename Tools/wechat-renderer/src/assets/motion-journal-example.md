# 动态实验刊：让过程自己说话

一篇技术文章里，最值得画出来的，往往是那些用很多句话才能讲清楚的过程。

**发出一条消息，看它经过哪里，再看结果如何回来。** 正文讲述经验，图解呈现关系。读者可以停下来观察，也可以继续往下读。

```wechat-flow
title: 一条消息，连接两块屏幕
steps:
  - 手机
  - 飞书
  - Codex
  - 电脑
returnLabel: 执行结果回到手机，开始下一轮对话。
```

## 把过程放到纸面上

版面从一张图切回文字。大号章节序号划出新的起点，正文保持适合连续阅读的大小与行距。

### 让动态承担解释

光点按固定顺序经过四个节点。即使暂停，箭头与编号也能说明方向。动画表达的是一个简化的消息往返过程。

> 图解适合展示关系，正文适合交代细节。两者交替出现，文章就有了呼吸的空间。
